FPS — Forgent Power Solutions Inc. Class A Common Stock

2026-09-16 미국장 상승 종목 심층분석 · SEC 공시 + 실적콜 + 뉴스 기반 · Claude Code CLI · fable
FPS+9.50%거래량 6.55배$9.55B비중 판단 보통

1. 결론 — 비중 판단

비중 판단: 보통

  • FY26 4분기(6월 분기) 매출 $462M(+94% YoY), 수주 $1,503M(북투빌 3.3배), 수주잔고 $3.0B(+256%)로 성장의 실체가 8-K로 확인됨. FY27 가이던스(매출 $2.4~2.6B, 중간값 +76%)는 수주잔고 $3.0B만으로 이미 1.2배 커버됨(계산치).
  • 종가 $31.36은 FY27 조정 EPS 가이던스 중간값 $1.33 기준 약 23.6배(계산치)로, 76% 성장 가이던스 대비 부담이 크지 않음. 60일 -50.5%, 52주 고점 대비 -51.4%의 급락을 거쳐 IPO 공모가($27)·유상증자가($29.50) 부근까지 내려온 상태.
  • 다만 TTM 잉여현금흐름 -$97.7M, IPO·유상증자 순수익 $800M 전액이 기존 오너(Neos 계열) 지분 상환에 사용된 Up-C 구조, TRA 부담, 데이터센터·AI 투자 의존, 관세·원자재 리스크가 겹쳐 있어 '적극'으로 올리기엔 근거가 부족함.
  • 최근 60일 -50% 급락의 원인이 제공된 공시로는 특정되지 않으며, 매출총이익률·영업이익률·순부채가 제공 자료에 없어 마진 구조와 레버리지를 검증하지 못한 점이 판단을 '보통'에 묶는 핵심 이유임.

2. 오늘 상승의 원인

확인된 촉매: 2026-09-15 8-K(FY26 4분기 실적 및 FY27 가이던스)

  • 8-K 보도자료(Exhibit 99.1)에 따르면 4분기 매출·조정 EBITDA·조정 순이익이 모두 5월 가이던스 상단을 초과했고, FY27 가이던스로 매출 $2.4~2.6B, 조정 EBITDA $575~625M, 조정 EPS $1.26~1.40을 제시함.
  • 뉴스 헤드라인(Yahoo Finance, ChartMill)도 "기록적 수주·$3B 백로그·FY27 76% 성장 가이던스"를 프리마켓 +10~13%의 원인으로 지목해 공시 내용과 일치함.
  • 거래량 20일 중앙값 대비 6.55배, 거래대금 $1.02B는 실적 이벤트에 따른 기관 재진입 또는 숏커버 성격으로 해석 가능하나, 어느 쪽인지는 자료상 구분 불가.
  • 참고로 상승 이전 60일간 -50.5%를 기록했으므로 오늘 상승은 '추세 전환'이라기보다 '급락 후 실적 확인에 따른 반등'으로 봐야 함. 급락 원인(락업 해제, 섹터 디레이팅 등)은 제공 공시에서 확인 불가.

3. 사업 구조 — 무엇을 팔아 어디서 돈을 버는가

제품 (10-Q MD&A 기준) - 데이터센터·전력망·에너지 집약 산업설비용 배전 장비 설계·제조. 주요 품목은 자동절체스위치(ATS), 건식·유입 변압기, 전기실(eHouse), 발전기 연결 캐비닛, 패널보드, PDU, 파워 스키드, RPP, 스위치보드, 스위치기어, 탭박스. - 세 가지 판매 유형: Custom Products(프로젝트별 설계, 소량 생산), Powertrain Solutions(Custom Products를 통합·스키드화한 시스템), Standard Products(공통 설계, 대량 생산). 현장 시운전·유지보수 서비스도 제공. - 회사는 "engineered-to-order" 방식의 Custom Products와 Powertrain Solutions 특화를 강조하며, 배전 장비는 고장 시 결과가 치명적이라 고객이 가격보다 신뢰성·안전성을 우선한다고 주장함.

고객군 - 직접 구매: 기술·전력·유틸리티·산업 기업. 간접: OEM·인테그레이터, 데이터센터·발전소·T&D 건설 계약자, 전기자재 유통사. - 회사가 제시한 4대 수요 축: (i) 클라우드·AI용 데이터센터 투자, (ii) IPP의 신규 발전 설비, (iii) 유틸리티의 T&D 증설, (iv) 제조업 리쇼어링.

생산 거점: 미네소타·텍사스·메릴랜드·캘리포니아·멕시코. 본사는 미네소타 데이턴.

매출 구성: 제품 유형별·고객군별 매출 비중은 제공된 발췌에 없음 → 공시상 확인 불가.

경쟁 위치: 10-K는 "leading designer and manufacturer"로 자칭하나, 시장점유율·주요 경쟁사 명칭은 제공 발췌에 없음. 리스크 섹션에서 "경쟁 환경에서 실패 시 점유율 상실"과 "대형 고객의 가격 인하·불리한 계약조건 요구"를 명시해, 대형 하이퍼스케일러 대상 가격 협상력이 절대적이지는 않음을 시사.

지배구조: Up-C 구조. Class A 274.5M주, Class B 29.9M주(2026-09-08 기준). Neos Partners, LP가 유의미한 영향력을 보유하며 TRA(Tax Receivable Agreement)로 기존 오너에게 세금 혜택이 귀속됨. 2026-02-06 IPO($27), 2026-03-30 유상증자($29.50)를 거쳤고 비가속 신고자(non-accelerated filer)로 SOX 404(b) 감사인 인증 없음.

4. 실적·재무 분석

분기 지표 정합성 주의: 제공된 지표표의 '최근 분기 매출 $378.7M'은 8-K의 4분기 매출 $462M과 다름. FY26 연매출 $1,420M과 4분기 $462M을 감안하면 $378.7M은 직전 분기(2026년 3월 분기)로 추정됨. 이 경우 4분기 QoQ 성장률은 약 +22%(계산치).

성장의 질 | 항목 | FY26 4분기 | FY26 연간 | |---|---|---| | 매출 | $462M (+94% YoY) | $1,420M (+89% YoY) | | 수주(Bookings) | $1,503M (+375% YoY) | - | | 북투빌 | 3.3배 | - | | 수주잔고 | $3.0B (+256% YoY) | - | | 순이익 | $66M (마진 14.3%) | $106M (+508%) | | 조정 EBITDA | $113M (마진 24.4%) | $323M (+91%) | | 영업현금흐름 | $74M (+$81M YoY) | - |

  • 단가·물량·믹스 분해는 제공 자료에 없음. 다만 회사가 Custom·Powertrain 중심을 강조하고, 10-K 리스크에 "Powertrain Solutions 매출 확대 전략은 고객 집중을 초래할 수 있음"이 명시된 점에서 성장의 상당 부분이 대형 데이터센터 프로젝트 물량으로 추정됨(추정).
  • 4분기 순이익 $66M이 연간 $106M의 62%를 차지(계산치). 하반기로 갈수록 수익성이 급격히 개선된 구조로, 전분기 대비 순이익률 약 800bp 개선은 IPO 관련 일회성 비용 소멸과 레버리지 효과가 섞였을 가능성이 있으나 분해는 공시상 확인 불가.

마진 방향성 - 조정 EBITDA 마진: FY26 연간 22.7%(계산치) → 4분기 24.4% → FY27 가이던스 중간값 24.0%(계산치). 회사는 4분기 수준의 마진이 FY27에도 유지된다고 보는 셈. - 매출총이익률·영업이익률은 제공 지표에 없음 → 공시상 확인 불가. 10-K가 전기강·구리·알루미늄 가격과 관세 전가 실패 시 마진 훼손을 반복 언급하는 만큼, GAAP 총이익률 추이는 반드시 원문에서 별도 확인 필요.

현금흐름·재무 건전성 - TTM 잉여현금흐름 -$97.7M(제공 지표). 4분기 영업현금흐름 $74M로 흑자 전환했으나, 연간으로는 설비 확장 투자가 영업현금을 초과했음을 의미. 10-K는 "확장을 예정 기간 내 완료하지 못하면 성장 목표 달성 불가"를 리스크로 명시. - IPO·유상증자 순수익 $491.8M + $308.6M = $800.4M은 전액 기존 Opco 오너(Forgent Parent II·III LP) 지분 상환에 사용됨(10-Q MD&A). 즉 공모 자금이 회사 성장 자본으로 유입되지 않았음. 현금·차입금·순부채 규모는 제공 발췌에 없음 → 공시상 확인 불가. 10-K가 "부채가 현재 및 미래 운영을 제한할 수 있음"을 리스크로 든 점에서 유의미한 차입이 존재하는 것으로 추정. - 조정 EPS: FY27 가이던스 중간값 $1.33이 "95% 성장"이라는 회사 설명을 역산하면 FY26 조정 EPS는 약 $0.68(계산치). GAAP 순이익 $106M ÷ 총주식 304.4M주 = 약 $0.35(계산치)로, 조정 EPS와 GAAP EPS 간 괴리가 큼. 조정 항목 내역은 공시상 확인 불가.

5. 성장 드라이버

  1. 수주잔고 $3.0B의 매출 전환 - 회사는 FY27 매출 $2.4~2.6B를 제시. 잔고가 가이던스 중간값의 1.2배(계산치)이므로 물량 자체는 확보된 상태. - 검증 포인트: FY27 1분기(9월 분기) 10-Q에서 잔고 중 12개월 내 인식 예정 비중, 신규 수주가 1분기 매출을 계속 상회하는지(북투빌 >1 유지), 취소·연기 여부.

  2. 데이터센터·AI 투자 사이클 - 10-K는 "성장은 신규 데이터센터 투자에 부분적으로 의존하며, 이는 AI 개발에 대한 지속적 관심에 의존"한다고 명시. 4분기 수주 +375%는 이 사이클의 직접 수혜. - 검증 포인트: 고객 집중도(10-K 원문 상위 고객 비중), Powertrain Solutions 매출 비중 변화, 하이퍼스케일러 capex 가이던스 변화.

  3. 생산 능력 확장 - 10-K가 "확장을 예정대로 완료하지 못하면 성장 목표 달성 불가"를 리스크로 명시한 것은 역으로 확장이 진행 중임을 뜻함. TTM FCF 적자의 원인으로 추정. - 검증 포인트: 분기 capex 규모와 FCF 전환 시점, 신규 캠퍼스 가동률, 납기 리드타임 언급.

  4. 마진 구조 안착 - 회사는 FY27 조정 EBITDA $575~625M(마진 약 24%)을 제시. 관세·원자재 가격 전가가 전제. - 검증 포인트: 1분기 GAAP 총이익률, 조정 EBITDA와 GAAP 영업이익 간 괴리 축소 여부.

  5. 유틸리티 T&D·IPP·리쇼어링 다변화 - 회사가 제시한 4대 수요 축 중 데이터센터 외 3개 축의 실제 기여도는 제공 자료에 없음 → 공시상 확인 불가. - 검증 포인트: 최종시장별 매출 분해 공개 여부.

6. 리스크

  1. 공모 자금이 회사에 남지 않은 Up-C·TRA 구조: IPO·유상증자 순수익 $800.4M 전액이 기존 오너 지분 상환에 쓰였고, TRA에 따라 세금 절감 효과가 TRA 참여자(기존 오너)에게 귀속됨. 10-K는 TRA 지급이 실제 혜택을 크게 초과하거나 가속화될 수 있다고 명시. Class A 주주는 성장 자본 유입 없이 희석과 TRA 부담만 안은 구조.

  2. Neos Partners의 지배력과 매도 오버행: IPO에서 45.3M주, 유상증자에서 23.7M주를 매도주주가 처분했고 Class B 29.9M주가 남아 있음. 10-K는 Neos의 이해가 다른 주주와 충돌할 수 있음을 명시. 60일 -50% 급락과 추가 매도 가능성의 연관은 공시상 확인 불가하나 상시 오버행으로 봐야 함.

  3. 관세·원자재 전가 실패 시 마진 훼손: 10-K는 전기강·탄소강·알루미늄·구리 가격 상승과 수입 관세를 전가하지 못하면 "마진에 상당한 영향"이라고 명시. 멕시코 생산 거점이 있어 관세 정책 변화에 직접 노출. 조정 EBITDA 마진 24% 가이던스는 전가 성공을 전제.

  4. 데이터센터 단일 사이클 의존과 고객 집중: 10-K는 Powertrain Solutions 확대가 소수 고객 집중을 초래하고, 한 고객의 대규모 주문 감소가 사업에 악영향을 줄 수 있다고 명시. 대형 주문의 예측 불가능한 발주·취소로 분기 실적 변동성이 커질 수 있음도 리스크로 기재. 수주잔고가 "예상 금액·시점에 매출로 전환되지 않을 수 있다"는 문구도 있음.

  5. 내부통제 검증 부재와 인수 통합: 비가속 신고자로 SOX 404(b) 감사인 인증이 없음. 10-K는 "Business Acquisitions" 통합 리스크를 별도 명시(인수 상세는 제공 발췌에 없음 → 공시상 확인 불가). 상장 7개월 차 기업의 회계·통제 성숙도는 아직 검증되지 않음.

7. 비중 판단의 근거와 체크포인트
