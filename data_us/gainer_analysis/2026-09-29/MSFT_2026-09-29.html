비중 판단: 보통

  • 결론적으로 벤치마크 비중 수준의 보유는 정당화됩니다. 다만 오늘 가격에서 비중을 크게 늘리는 판단은 FY27 1분기 실적을 확인한 뒤로 미루는 것이 합리적입니다.

1) Azure·AI 인프라 용량 확대 - 회사 주장: 2년 내 총용량 약 2배. 신규 GPU를 입고부터 가동까지 걸리는 시간(dock-to-live)을 약 50% 단축(실적콜). - 실현 조건: MD&A가 명시한 부지, 전력, 네트워크, GPU 조달이 제때 이뤄져야 합니다. - 검증 포인트: FY27 1분기 Azure(또는 새 지표 체계의 해당 항목) 성장률이 40% 안팎을 유지하는지, 용량 제약 발언이 나오는지 확인합니다.

2) 상업용 RPO라는 수주 잔고의 매출 전환 - 근거: 3분기 RPO $627B(+99%)입니다. - 실현 조건: 잔고의 매출 인식 속도와 특정 대형 고객 집중도가 관건입니다. 고객 집중도는 공시상 확인 불가입니다. - 검증 포인트: FY27 1분기 RPO가 전분기 대비 다시 늘어나는지 봅니다. $625B에서 $627B로 정체된 흐름이 이어지는지가 핵심입니다. 10-K에 공시된 1년 내 인식 비중도 확인합니다.

3) M365 Copilot·에이전트 수익화 - 근거: M365 Commercial cloud가 +17%에서 +19%로 가속했습니다. 실적콜에서 Copilot 워크로드 처리량이 연초 대비 4배라고 언급했습니다. - 실현 조건: 좌석 확장과 ARPU 상승이 이어지고, 에이전트 관리 제품(Agent 365)이 수익화돼야 합니다. - 검증 포인트: M365 Commercial 성장률 20% 돌파 여부, Copilot 좌석 수 공시 여부를 봅니다.

4) 자체 칩·자체 모델(MAI)을 통한 원가 절감 - 회사 주장(실적콜): - Maia 200은 기존 최신 하드웨어 대비 가격 대비 성능이 30% 우수합니다. - MAI 모델을 Maia 200에서 구동하면 전력 대비 성능이 40% 개선됩니다. - MAI-Code-1-Flash는 중간값 토큰 사용량이 10% 적습니다. - 실현 조건: 자체 모델 품질이 프런티어 모델과 충분히 가까워야 합니다. 동시에 외부 모델 조달 조건이 유지돼야 합니다. - 검증 포인트: 매출총이익률 추이와 Microsoft Cloud 총이익률 방향을 확인합니다.

5) 보안(Project Perception)과 소버린 클라우드 - 회사 주장: MAI-Cyber-1-Flash로 Mythos급 성능을 50% 낮은 비용에 낸다고 밝혔습니다. Mistral 모델을 Sovereign Cloud에 탑재합니다(실적콜). - 검증 포인트: 보안 매출 성장률의 별도 공시 여부를 봅니다. 현재 발췌에서는 공시상 확인 불가입니다.

5-1. 실적콜에서 읽히는 것 (FY26 4분기, 2026-07-29)

톤과 자신감의 근거 - 나델라 CEO는 "기록적 회계연도의 매우 강한 마무리"로 시작해 연간 실적을 숫자로 먼저 제시했습니다. 매출 $331B(+18%), Microsoft Cloud $214B(+27%), Azure $100B(+41%)입니다. - 이후 인프라(용량·칩), 플랫폼(모델 선택), 자체 모델 순으로 공급 측 효율을 강조했습니다. 자신감의 근거가 "수요"보다 "단위원가 개선과 공급 확대 속도"에 맞춰져 있다는 점이 특징입니다. - 화법의 변화도 보입니다. OpenAI 의존을 전면에 내세우기보다 "모든 모델은 대체 가능하다(substitutable)"는 멀티모델·회복력 논리를 여러 번 반복했습니다. - 10-Q 문구도 함께 바뀌었습니다. - 2분기 10-Q: 양사 간 "상호(reciprocal) 수익배분 약정" - 3분기 10-Q: 회사가 "수익배분 지급을 계속 받을 것" - 2026년 4월 파트너십 재조정이 있었음을 시사하지만, 구체 조건은 공시상 확인 불가입니다.

Q&A에서 반복된 질문과 방어 지점 - ROI 질문(Goldman Sachs): CFO는 "계산 방식이 바뀌지 않았다"고 답했습니다. 이어 TAM 확대에 대한 확신과 마진 수단(칩, 모델 다변화, 운영 효율)을 나열했습니다. 정량적인 ROIC나 투자 회수 기간은 제시하지 않았습니다. "매일 조금씩 나아지는 꾸준한 작업(grind work)"이라는 정성적 방어에 그친 점이 회피성 답변으로 읽힙니다. - 보안 질문(Deutsche Bank): 최근 프런티어 모델 출시로 사이버 경쟁 구도가 바뀐 데 대한 질문이었습니다. 이는 시장이 AI 모델 발전을 MSFT 보안 사업의 위협으로 보고 있음을 보여줍니다. 회사는 멀티모델 비용 우위(90%는 자체 Flash 모델, 10%만 프런티어 모델)로 방어했습니다. - 발췌상 첫 질문도 모델 선택·멀티모델 관련으로 보입니다. 반복된 핵심 주제는 Capex ROI, 모델 원가, 외부 모델 의존도입니다. - 제공된 발췌는 중략돼 있어 FY27 가이던스 수치(매출, Capex, 마진)는 확인할 수 없습니다.

공시에는 없고 콜에서만 드러난 정보 - 분기 31개, 연간 88개 데이터센터 신설과 분기 약 1GW 증설 - 신규 GPU 가동까지 걸리는 시간 약 50% 단축 - Maia 200 가격 대비 성능 +30%, MAI 모델 전력 대비 성능 +40% - 복수 모델 공급자를 쓰는 고객 수 5배 증가 - 자체 추론 모델 MAI-Thinking-1을 포함한 신규 모델 10여 개 발표 - Cobalt 200 랙을 25개 이상 데이터센터에 배치 예정 - Mistral과의 소버린 클라우드 파트너십 - AMD Helios, NVIDIA Vera Rubin 초기 도입 계획

6. 리스크

  1. Capex 부담과 FCF 전환율 하락 - MD&A는 인프라 투자가 영업이익률을 낮출 수 있다고 명시합니다. - FCF 마진(약 20%)은 영업이익률(45%)의 절반 이하입니다. - 실적콜에서 ROI를 정량적으로 제시하지 않았습니다. AI 수요가 둔화되면 감가상각 부담이 이익을 압박하는 구조입니다.
  2. 인프라 공급 제약 - MD&A는 데이터센터가 인허가된 부지, 예측 가능한 전력, 네트워크, GPU 가용성에 의존한다고 명시합니다. - Azure 성장이 수요가 아니라 공급 제약에 묶이는 시나리오입니다.
  3. OpenAI 관계와 RPO 집중도의 불투명성 - 2025년 10월과 2026년 4월, 두 차례 계약이 재조정됐고 수익배분 관련 문구도 바뀌었습니다. - RPO $627B 중 특정 고객 비중은 공시상 확인 불가입니다. - RPO가 전분기 대비 정체($625B→$627B)된 것이 신규 대형 계약의 둔화를 뜻하는지 확인이 필요합니다.
  4. 세그먼트·지표 재편에 따른 비교 가능성 저하 - 2026-09 8-K로 FY27부터 세그먼트와 투자자 지표가 바뀌었습니다. - 기존에 추적하던 지표(예: Azure 성장률)가 새 체계에서 같은 정의로 유지되는지 확인해야 합니다. 발췌상 공시상 확인 불가입니다.
  5. 소비자 부문 약세와 환율 효과 소멸 - Windows OEM(-2%)과 Xbox(-5%)가 역성장 중입니다. - 3분기 10-Q는 달러 약세가 보고 매출을 늘렸다고 밝혔습니다. 환율 방향이 바뀌면 보고 성장률이 낮아질 수 있습니다. - 관세 등 무역정책에 따른 디바이스 공급망 비용 리스크도 명시돼 있습니다.
